# Дополнительная проверка Mea musica

Проверка проведена 9 октября 2026 года на Windows. Из восьми оставшихся записей удалось скачать ещё три. Они импортированы в установленный Playerium 1.7.6 и добавлены в «Проверка Mea musica — 1.7.6»: теперь 170 из 175. Каждый новый файл полностью декодирован FFmpeg; запуск воспроизведения и сохранение плейлиста после перезапуска проверены. Сверка аудиофингерпринта с эталонным мастер-файлом не проводилась.

| Запись | Проверенный источник | Длительность файла |
| --- | --- | --- |
| THE PINBALLS — Blues of Shichiten Battou | [Официальное альбомное аудио с японским названием](https://www.youtube.com/watch?v=Z2Sc1X_v5wY) | 189,61 с |
| Pitbull, AFROJACK, Ne-Yo, Nayer — Give Me Everything (feat. Nayer) | [Официальное аудио](https://www.youtube.com/watch?v=KVuMAM80PIA) | 252,92 с |
| Schmalgauzen — Jessica - Single Version | [Music2019, страница записи](https://hit.music2019.su/track/3158) | 203,30 с |

Music2019 подключён как дополнительный источник конкретной проверенной записи. Общий поиск по этому сайту пока не подтверждён: его страницы поиска возвращали ошибку. Авторское происхождение размещённого там файла не подтверждено, источник не помечается официальным. Ссылка на аудио извлекается заново со страницы при загрузке; временный адрес CDN не хранится в реестре записей.

THE PINBALLS сопоставляется по проверенному соответствию английского и японского названия только для этого исполнителя. У Pitbull учитываются одинаковые полные составы исполнителей независимо от их порядка. Live, короткие версии, ремиксы и другие исполнители по-прежнему отклоняются.

## Пока не удалось скачать точные версии

- System Of A Down — ATWA: официальные YouTube-записи недоступны загрузчику; Audiomack не вернул доступный аудиоформат, дополнительный публичный плеер также не отдал файл. Musify помечает запись недоступной.
- Pixies — Where Is My Mind? - 2007 Remaster: официальный YouTube ограничил загрузку; SoundCloud не предоставляет полный доступный формат; Bandcamp не отдал аудиоформат для загрузки. Неподтверждённый Bandcamp-адрес не добавлен в реестр резервных источников.
- Foo Fighters — Today's Song: официальные YouTube и SoundCloud не предоставили доступный полный файл. Магазин исполнителя предлагает платное скачивание.
- GRABAR — Нерухомість и GRABAR, YUVI — На подобу тобі: доступные найденные публикации включают объединённый клип, а не две точные отдельные версии. Его не использовали как замену.

Результаты реальных загрузок и воспроизведения сохранены локально в `build/gap-sources/installed-new-tracks.json`. Эти файлы содержат локальные пути пользователя и не публикуются в репозитории.
