# Google Диск для Playerium

Один раз настройте проект Google Cloud, затем подключите **один и тот же аккаунт Google** в Playerium на компьютере и телефоне. Создание и удаление песен доступно с обоих устройств; компьютер не является главным устройством.

## 1. Создайте проект

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) под своим аккаунтом.
2. Создайте проект, например **Playerium Personal**.
3. В **APIs & Services → Library** найдите **Google Drive API** и нажмите **Enable**.
4. Откройте **Google Auth Platform → Branding**. Укажите название Playerium и свой адрес электронной почты для поддержки и контактов разработчика.
5. В **Audience** выберите **External**. Для первого подключения в режиме **Testing** добавьте свой Google-аккаунт в **Test users**.
6. В **Data Access → Add or remove scopes** добавьте только `https://www.googleapis.com/auth/drive.file`.

Это разрешение ограничивает доступ файлами, созданными или разрешёнными для приложения. Доступ ко всему вашему Диску не требуется. [Описание разрешений Google](https://developers.google.com/workspace/drive/api/guides/api-specific-auth).

## 2. Настройте Windows

1. В том же проекте откройте **Clients → Create client**.
2. Выберите тип **Desktop app**, имя **Playerium Windows**.
3. Скачайте JSON-файл клиента. Храните его у себя; не загружайте в GitHub и не отправляйте в чат.
4. В Playerium откройте **Настройки → Google Диск → Настройка подключения → Загрузить файл настройки** и выберите этот JSON.
5. Нажмите **Подключить Google Диск**. В открывшемся системном браузере войдите в Google и разрешите доступ. После подтверждения вернитесь в плеер.

Файл должен содержать раздел `installed`, а не `web`. Playerium использует вход для настольного приложения с PKCE и локальным адресом возврата. [Документация Google](https://developers.google.com/identity/protocols/oauth2/native-app).

## 3. Настройте Android

1. В **том же проекте** создайте ещё один клиент типа **Android**, имя **Playerium Android**.
2. В поле **Package name** укажите `com.playerium.music`.
3. В поле **SHA-1 certificate fingerprint** вставьте отпечаток сертификата официального APK Playerium:

   ```text
   D1:D1:67:5F:38:F3:34:1A:9C:CA:16:F4:1D:4A:A5:6B:01:7D:92:6B
   ```

4. Сохраните клиента. Подождите несколько минут, чтобы настройки Google вступили в силу.
5. Установите официальный APK из релиза GitHub. В **Настройки → Google Диск** нажмите **Подключить Google Диск**, выберите тот же аккаунт и подтвердите разрешение.

JSON-файл на телефон переносить не нужно. Android определяет клиента по пакету и сертификату через Google Play services. Телефону нужны работающие Google Play services. APK собственной сборки с другим сертификатом потребует отдельного Android-клиента с его SHA-1. [Авторизация Android](https://developer.android.com/identity/authorization).

## 4. Уберите ограничение тестового входа

После проверки подключения откройте **Audience** и переведите приложение в **Production** кнопкой **Publish app**. Это публикация настроек OAuth, а не публикация Playerium в Google Play.

В режиме Testing доступ с разрешением Drive может потребовать повторного входа через семь дней. Production снимает именно это тестовое ограничение; отзыв разрешения, неактивность и правила Google всё равно могут потребовать повторный вход. Если Google просит дополнить сведения приложения, заполните показанные обязательные поля. [Сроки действия Google OAuth](https://developers.google.com/identity/protocols/oauth2#expiration).

## Как работает синхронизация

- В Диске появится папка **Playerium** с музыкой, обложками и журналом изменений. Иногда при одновременном первом входе возможны две одноимённые папки: приложение учитывает обе.
- Добавленные или скачанные песни отправляются с любого устройства. После подключения другого устройства песни автоматически скачиваются и появляются в «Добавленных».
- Одинаковые файлы сопоставляются по SHA-256. Разные записи, ремастеры или форматы остаются разными файлами.
- Любимые песни и обычные плейлисты синхронизируются. Названия альбомов не добавляются в медиатеку.
- Удалённая песня исчезает из медиатеки на обоих устройствах после синхронизации. Резервный файл остаётся в облаке; восстановление доступно в **Google Диск → Удалённые песни**. Удаление старого плейлиста не восстанавливает его автоматически.
- Оригинальные импортированные файлы на диске компьютера и в выбранной папке телефона не удаляются. Приложение удаляет только свои локальные облачные копии. Отключение Google Диска сохраняет локальную музыку.
- Без сети используется локальная музыка. Очередь отправки сохраняется; Android выполняет её через фоновую задачу, Windows — пока приложение работает, включая значок в трее. При закрытом приложении Windows отправка продолжится при следующем запуске.
- Файлы загружаются частями. Обрывы соединения не требуют повторной отправки всей песни. Скачанная музыка проверяется по SHA-256 перед добавлением.
- Локальные облачные копии занимают место на каждом устройстве. Облачная корзина занимает место на Google Диске; это резервное хранение, а не освобождение квоты.

## Если подключение не работает

Проверьте, что Drive API включён, оба клиента созданы в одном проекте, аккаунт добавлен в Test users при режиме Testing, а Android SHA-1 соответствует установленному APK. Для Windows нужен Desktop app JSON. Ошибки квоты или недостатка места отображаются в разделе синхронизации. Оплата отдельного сервера не нужна; ограничения и возможные тарифы Google зависят от аккаунта и объёма API-запросов. [Квоты Drive API](https://developers.google.com/workspace/drive/api/guides/limits).

Первую проверку проводите с несколькими песнями: добавьте на телефоне, проверьте появление на ПК; затем добавьте на ПК и проверьте телефон. Проверьте удаление, восстановление и прослушивание без сети. Реальная проверка вашего Диска требует завершённой настройки и входа на обоих устройствах.
