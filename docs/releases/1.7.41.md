# Playerium 1.7.41

- Ускорено чтение облачной медиатеки на Android: больше параллельных запросов, а уже полученные события сохраняются с проверкой версии файла. После прерывания их не нужно скачивать заново.
- Убраны лишние чтения журнала перед началом скачивания песен. Очередь загрузок больше не считается исходящими изменениями.
- Исправлена устаревшая обложка в шторке: при переключении песни старая картинка не должна подменять текущую. До получения обложки показывается нейтральная заглушка.
- Карточка «Далее», очередь и предзагрузка обложек используют реальный порядок воспроизведения Android при перемешивании.
- Повторное включение перемешивания создаёт свежий случайный порядок без перезапуска текущей песни и сброса позиции. Исправлена обработка повторяющихся записей в очереди.
- Перестановка и удаление следующих песен сохраняют текущую запись и её позицию при перемешивании.

В пределах одного прохода случайный порядок остаётся постоянным. Повтор всей очереди повторяет этот порядок; чтобы создать новый, выключите и включите перемешивание.

Файлы релиза: подписанный APK Android, установщик и переносимая версия Windows. Контрольные суммы приведены в SHA256SUMS.txt.
