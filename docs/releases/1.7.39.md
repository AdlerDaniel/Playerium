# Изменения

- Исправлен порядок авторизации быстрой синхронизации при первом входе на новом устройстве. Неудачное подключение можно повторить без сохранения незавершённой сессии.

- Исправлено ожидание всей очереди скачиваний перед добавлением песен в медиатеку Android после повторного входа.
- Фоновая синхронизация освобождает очередь между файлами, позволяя приложению добавлять уже готовые песни по мере загрузки.
- Проверенные скачанные записи восстанавливаются локально без повторного запроса аудиофайла к Google Диску.
- Ускорено первое резервное чтение медиатеки с Google Диска: убраны повторные запросы метаданных каждой записи журнала.
- В настройках видны этапы синхронизации и счётчик чтения облачного журнала; устаревший прогресс сбрасывается перед новой попыткой.
- Восстановлена сборка Windows после удаления архива FFmpeg поставщиком: используется сохранённый исходный архив с прежней контрольной суммой.
