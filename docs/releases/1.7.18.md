## Изменения

- Добавлена синхронизация музыки через Google Диск на Windows и Android: песни можно добавлять с любого устройства.
- Синхронизируются обложки, любимые песни и плейлисты. Облачные песни сохраняются локально для прослушивания без сети.
- Удаление действует на обоих устройствах; резервные копии можно восстановить в настройках Google Диска.
- Добавлена очередь загрузок с продолжением после обрыва связи и проверка целостности скачанной музыки.
- Добавлена инструкция первоначального подключения Google Cloud в настройках плеера.
