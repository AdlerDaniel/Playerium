- Заголовки «Название», «Дата добавления» и значок часов сортируют таблицу. Повторное нажатие меняет направление; стрелка и состояние заголовка показывают текущий порядок. Очередь воспроизведения соответствует отсортированному списку.
- В настройках появился раздел «Громкость музыки»: количество готовых песен, прогресс, ошибки, проверка готовности и ручной запуск обработки. Завершение отображается явно; повторный запуск обрабатывает недостающие записи и повторяет неудачные задания.
- Выбор трека в уже загруженном плейлисте Android использует короткую команду вместо повторной отправки и разбора всей очереди. Проверка доступа выполняется при открытии конкретного файла; поиск обложек для всех соседних песен убран из запуска.
- Эквалайзер не пересоздаётся при каждом нажатии на трек и сохраняет настройки после перезапуска службы. Для локальных файлов уменьшен стартовый порог буферизации.
- В настройках показывается время последнего запуска звука. Добавлена проверка реального запуска аудио из строки плейлиста на 300 записей, включая первый запуск и выбор другой строки.
