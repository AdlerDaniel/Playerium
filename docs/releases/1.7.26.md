- Обложки остаются видимыми при обновлении страниц. Новая картинка заменяет прежнюю после декодирования; неизменившиеся коллажи сохраняются, портреты исполнителей поднимаются из локального кеша до первого отображения.
- На телефоне добавлены общие внутренние поля по 20 px, отступы внутри карточек настроек и прозрачная область управления плейлистом. Фон остаётся единым на всю ширину экрана.
- Выбор трека из плейлиста на Android использует сохранённую нормализацию и отдельное быстрое чтение нативного кеша. Готовые измерения больше не ждут анализа другой песни или сетевых запросов.
- Подготовка песни отображается кружком загрузки в строке и общей подписью. Во время ожидания доступны остальные страницы; пауза отменяет отложенный запуск. Для быстрого запуска индикатор не мигает.
- Добавлены индикаторы загрузки исполнителя и поиска с сохранением доступного содержимого. Убрано затухание целой страницы при входе и навигации.
- Обновления медиатеки объединяются, чтобы загрузка и синхронизация не перестраивали экран после каждого уведомления. Ускорена проверка удалений, сохранено поведение очереди синхронизации.
- При первой подготовке ещё не измеренной записи может потребоваться время; результат кешируется, а громкость не меняется посреди песни.
