# Проверка скачивания 1.7.3 — 7 октября 2026

Muzend добавлен как дополнительный источник в общий поиск Windows и Android.
Результаты объединяются с каталоговыми метаданными, варианты исключаются;
источник не помечается как официальный. Допускаются только HTTPS MP3-файлы
из muzend.net/uploads/music/ без параметров запроса, а не произвольные адреса.
Из найденной записи создаётся описание для существующего загрузчика;
название и исполнитель берутся из карточки и каталога, не из рекламных тегов MP3.

Живая проверка через DesktopMusic в Electron: поиск Dorofeeva 747 вернул
полную запись, скачивание через комплектные yt-dlp/FFmpeg сохранило
7 041 785 байт, длительность 174,054 секунды. Повторное чтение MP3 подтвердило
title=747, artist=DOROFEEVA, album=747 - Single и встроенную обложку.
Удаление через тот же адаптер удалило сохранённый файл и сопутствующие данные.
Загрузка именно правообладателем на Muzend не подтверждена.

Проверки браузера на обеих платформах покрывают объединение в один результат,
сохранение метаданных, отбрасывание ремикса и стороннего адреса и отсутствие
названия источника в интерфейсе. Живое скачивание Muzend на физическом
телефоне не проверено; этот результат относится к Windows.

## Предыдущая проверка 1.7.2

На Windows обычное TLS-соединение yt-dlp с YouTube завершалось тайм-аутом,
при этом Electron получал страницы. Комплектный curl_cffi с профилем Chrome
устранил воспроизводимый отказ. Отключение проверки сертификатов не используется.

Поиск YouTube Music через плоский список yt-dlp возвращал названия без
исполнителей и длительности. Теперь Windows и Android запрашивают каталог
песен напрямую; общий обработчик извлекает авторские аудиозаписи ATV,
исполнителей, альбом, длительность и обложку. Клипы OMV исключены.

Через настоящий Electron, комплектные yt-dlp и FFmpeg найден и полностью
сохранён Nirvana — Smells Like Teen Spirit: 4 899 355 байт, 301,956 секунды.
Повторное чтение файла подтвердило title, artist и встроенную обложку.
Проверочные файлы сохранялись во временную папку и удалены после проверки.

Для DOROFEEVA — 747 подтверждён официальный SoundCloud URL
https://soundcloud.com/dorofeeva/747a1: экстрактор возвращает DRM protected.
Официальная ссылка https://orcd.co/_747_ указывает также на альбом YouTube Music
OLAK5uy_kfUrTEYxc3buoYTkRblpqlc6Dyw4gjEZ8; его оригинальная запись недоступна
в проверенном соединении, а поиск песен не возвращает подходящего оригинала.
Полное скачивание 747 не подтверждено. Защита не обходится, превью,
перепубликации, ремиксы и клипы не подменяют оригинал.

Отдельно проверены передача, конвертация, теги, обложка, восстановление и
удаление через комплектные инструменты. Регрессионные проверки покрывают
каталоговые кредиты, отбор аудио, отсутствие повторов запросов и различие
защиты, сетевого отказа и ошибки хранения. Настоящий IPC Electron передаёт
чистое сообщение без префикса Error invoking remote method.

Android использует общий обработчик результатов и отдельный диагностический
тест в инструментальных проверках. Живое скачивание с физического телефона
и проверка сети пользователя не выполнены; Windows-профиль curl_cffi
не выдаётся за изменение сетевого стека Android.
