# Скрытие загрузок из галереи Android

С версии 1.7.4 новые загрузки в выбранную через Android папку сохраняются
в подпапку `Playerium Downloads` с маркером `.nomedia`. Маркер создаётся
до сохранения аудио и отдельных обложек. Родительская папка и её посторонние
фотографии не скрываются. Собственная папка приложения также содержит маркер.

При восстановлении медиатеки старые загрузки из выбранной папки копируются
в скрытую подпапку. Размер аудио проверяется перед публикацией, новая запись
сохраняется атомарно до удаления прежнего файла, обложки и JSON. Незавершённое
удаление старых файлов сохраняется в записи и повторяется при следующем запуске.
При потере доступа оригиналы остаются на месте; перенос повторяется после
возвращения разрешения и запуска приложения. Для скачанных файлов на основной
памяти и SD-карте Android 11+ обновляется системный индекс старых расположений.
Галереи с собственным кэшем могут обновить список с задержкой.

Идентификатор загрузки и прежний URI используются для сохранения ID трека,
избранного и ссылок в плейлистах. Playerium сканирует выбранные папки напрямую,
поэтому `.nomedia` не исключает музыку из его медиатеки.

Проверки: изменение URI и сохранение ID/избранного/плейлистов после перезапуска;
создание скрытой подпапки без маркера в родителе, повторное создание маркера,
сохранение и чтение обложки, восстановление защиты старого файла, отсутствие
обложки в MediaStore.Images после сканирования и удаление собственных файлов.
Проверка конкретной галереи на физическом телефоне пользователя не выполнялась.
