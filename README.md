# Playerium

**Playerium** — стильный музыкальный плеер в дизайне Spotify (1-в-1) для воспроизведения локальных аудиофайлов на компьютере и мобильных устройствах, с автоматическим обновлением через GitHub Releases.

---

## Возможности

- **Интерфейс Spotify 1-в-1**: темная тема (`#121212`, `#1ed760`), оригинальная сетка, адаптивные градиенты под цвет обложек, медиатека, плейлисты, карточки артистов и альбомов.
- **Поддержка локальной музыки**: воспроизведение MP3, FLAC, WAV, OGG, AAC/M4A с жесткого диска или памяти телефона.
- **Встроенный ID3/FLAC парсер**: чтение метаданных треков (артист, название, альбом, год) и извлечение встроенных обложек (APIC).
- **Синхронизированные тексты песен (.lrc / Karaoke)**: автоматическая прокрутка и караоке-подсветка при наличии файлов `.lrc` рядом с треком.
- **10-полосный эквалайзер на Web Audio API**: готовые пресеты (Bass Boost, Rock, Pop, Vocal, Flat и др.) и тонкая ручная регулировка от -12 dB до +12 dB.
- **Автообновления через GitHub Releases**:
  - При запуске приложение обращается к GitHub API репозитория `Playerium` и проверяет наличие свежих релизов.
  - При обнаружении новой версии показывает окно с описанием изменений (Changelog) и кнопкой скачивания обновленного `.exe` (для Windows) или `.apk` (для Android).
  - В разделе «Настройки» можно в любой момент проверить обновления вручную или указать собственный репозиторий.

## Форматы запуска и сборки

### 1. Запуск на компьютере прямо сейчас
- **`start.bat`** — мгновенный запуск в отдельном окне программы (App Mode) без установки тяжелых пакетов.
- **`start_electron.bat`** — запуск в окне Electron.

### 2. Сборка Windows приложения (.EXE)
Для создания установочного инсталлятора и портативной версии:
1. Запустите скрипт:
   ```bat
   build_exe.bat
   ```
2. По завершении в папке `dist\` будут созданы:
   - `Playerium Setup 1.0.0.exe` (инсталлятор для Windows)
   - `Playerium 1.0.0.exe` (портативная версия, не требующая установки)

### 3. Сборка Android приложения (.APK)
Для сборки мобильного приложения для смартфона:
1. Запустите скрипт:
   ```bat
   build_apk.bat
   ```
2. Скрипт синхронизирует все веб-ассеты в Android-проект (`android/app/src/main/assets`) и скомпилирует `Playerium.apk`.
3. Готовый APK файл можно передать на телефон и установить. В манифесте уже настроены разрешения для чтения локальной музыки (`READ_MEDIA_AUDIO`, `READ_EXTERNAL_STORAGE`) и фонового воспроизведения при заблокированном экране (`WAKE_LOCK`, `FOREGROUND_SERVICE`).

## Настройка GitHub Releases для автообновлений

1. Создайте на GitHub репозиторий с именем **`Playerium`** (например, `https://github.com/vash-login/Playerium`).
2. В настройках плеера в поле «Репозиторий GitHub» укажите: `vash-login/Playerium`.
3. Когда захотите выпустить обновление:
   - Создайте на GitHub новый Release с тегом выше текущего (например, `v1.0.1`).
   - Прикрепите к релизу собранный `Playerium-Setup-1.0.1.exe` и/или `Playerium-1.0.1.apk`.
   - При следующем запуске у вас (и всех пользователей) появится окно обновления с кнопкой скачивания свежего файла!
